## 项目

**[AI Tech Radar](https://github.com/timazc232/ai-tech-radar)**

**[物业助手](https://github.com/timazc232/wecom-qwen-assist)**  
微信 / 企微回调 + 通义千问辅助回复 + 工单工具调用 + 人工接管。本地能打开的最小生产链路，模型辅助人工，人不退出主责。

也接 GitHub Actions、Google Workspace（表格 / 邮件 / 日历）这类把每周重复劳动收成自动任务的活。
